## Current design directions to test

1. **Vintage ghost + pumpkin, but with a new composition**
   - Use an original ghost character language.
   - Limit the palette to 2–4 ink colors.
   - Add one strong seasonal phrase or badge.
   - Avoid reproducing any competitor's character arrangement, wording, or illustration.

2. **Botanical skeleton**
   - Original skeleton silhouette combined with a distinctive native-flower / herbarium composition.
   - Use a restrained vintage poster layout.

3. **Back-print haunted harvest**
   - Small left-chest mark + large original back illustration.
   - Focus on autumn harvest storytelling rather than a generic Halloween icon pile.

4. **Spooky club / collegiate badge**
   - Invent a fictional club identity and typography system.
   - Build a completely original emblem and supporting icons.

5. **Cute ghost micro-niche**
   - Choose a narrow audience (pet owners, teachers, book lovers, coffee fans, etc.).
   - Use original character poses and a short phrase.

## Research rule

The engine must treat public signals as evidence, not as exact competitor sales data. It should never invent a competitor's unit sales, conversion rate, revenue, or private analytics.

## Compliance rule

Use Etsy's official API for automated Etsy marketplace research. Do not build an Etsy page scraper. Etsy's Terms prohibit crawling/scraping without express permission, and Etsy's API documentation says screen scraping is not allowed.
